小学阶段标准解题流程

4步标准解题 SOP、必背公式与口诀

严格贴合小学阶段算理，不超纲、不套用复杂代数变形，每一步都有大白话原因解释。

01

找准“几选几”

先找出总数 n 写在字母右下角，再找出挑出的个数 m 写在右上角（Amn 或 Cmn）。

算理：这是搭好算式的地基，先定范围与数量。

02

做“交换测试”定 A 或 C

随便挑出选好的 2 人或 2 物互换位置：变成新方法用排列 A；还是同一种方法用组合 C。

算理：排列与组合唯一区别就是“顺序重不重要”，亲手换位最不易被绕晕。

03

代入算式巧计算

算 A 从 n 倒着连乘 m 个数；算 C 用 Amn ÷ Amm，若 m 较大先“大转小”。

算理：直接排列会把同一组人自己排队的 Amm 种重复全算进去，所以要除以它。

04

复杂题分步拆解再相乘

遇“先选再分”“分组”“0不在首位”，拆成几小步各算各的再相乘；无组名分组最后除以组名乱排倍数。

算理：分步完成用乘法；无组名消重对应 P045 高能时刻 2。

必背解题口诀（知识点梳理 第3模块）

“选人排排站，交换变不变？
变了就用 A，倒乘 m 个数；
不变就用 C，除以小排列。”

  • 排列数公式（P028） Amn = n × (n-1) × …（连乘 m 个数）
  • 组合数公式（P032 / P15） Cmn = Amn ÷ Amm
  • 大转小速算（P034） Cmn = Cn-mn
  • 必背特殊值（P034） C0n = 1， Cnn = 1， C1n = n
  • 先选再排规律（P038 / P042） Cmn × Amm = Amn
易错难点与避坑清单

4 大高频丢分坑：常见错法 → 错因 → 避坑检查动作

整理自《小学奥数排列组合知识点梳理》第4模块与讲义巩固拓展题。

坑 1：分不清“有顺序”还是“无顺序”

自我巩固 第7、8题 / P21
【常见错法】 看到“选 2 种”就一律用组合 C，如把“14 个车站往返车票”或“兄弟俩各挑 1 种不同棒棒糖”错算成 C。
【错因剖析】 没有看清选出来的东西有没有“对应到不同的人、角色或起点终点”。
【避坑检查动作】 动笔前强制做一次“交换测试”——把哥哥和弟弟选的口味互换，一样吗？不一样！所以必须用 A。

坑 2：分组问题中，忽略“有没有组名”

高能时刻 2 / P045
【常见错法】 把 10 人分成 3人、3人、4人三组（不区分组名），直接照搬有组名的答案 12600 或漏除重复倍数。
【错因剖析】 分 A、B、C 三组时，同一批人换个组名算新方法；若不区分组名，A、B、C 这 3 个组名自己排队产生的 A33 = 6 种情况其实是同一种分法。
【避坑检查动作】 圈出题目里有没有“甲乙丙 / A、B、C 组”字样。有组名先定特殊人数归哪组；无组名算完有组名结果后，记得除以组名排列数（3 个组就除以 6）。

坑 3：数字组数时，忘记“0 不能在最高位”

专属探索 第3、4题 / P26
【常见错法】 用 0、1、3、5、7、9 组三位数直接算 A36 = 120；或算四位“上升数”时把 0 算进去写成 C410。
【错因剖析】 0 放在最左边（首位）就不再是原来的位数了（例如 0123 是三位数，不是四位数）。
【避坑检查动作】 只要给的数字里包含 0，立刻在 0 下面画圈！算最高位或“上升数”时先排除 0；算“下降数”时 0 排在最后一位（个位）合法，可以选。

坑 4：算组合数时硬算大数，导致计算丢分

任务2 · 实践2 / P034
【常见错法】 计算 C810 或 C57 时，老老实实倒着乘 8 个数或 5 个数，结果乘错或除错。
【错因剖析】 忘记了组合数的“大转小”速算规律（选 8 个带走等于选 2 个留下）。
【避坑检查动作】 看到右上角数字 m 超过总数 n 的一半，立刻把它变成 n - m 再动笔算。
